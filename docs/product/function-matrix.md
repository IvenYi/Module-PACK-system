# 模组 / PACK MES 标准化功能矩阵 v0.2

日期：2026-10-22｜状态：范围与优先级建议，非客户签字需求

来源S1/S2/R定义见[调研报告](../research/materials-and-reuse-assessment.md)；业务对象和运行规则见[产品蓝图](blueprint.md)。飞书文档尚未纳入。用户已确认取消通用表单、电子签名及认证。作业收敛为工序内标准动作；详细复用清单见[逐项审查](../architecture/edhr-reuse-audit.md)。下文PK编号对应[PACK行业设计](pack-domain-design.md)，新增行业字段与规则均区分材料依据和设计建议。

## 1. 阅读方式

- **P0**：建议作为首条真实产线的基本闭环；开发按切片逐步完成。设备/ERP未就绪时，可用模拟器或受控导入验证，但不能据此声称真实接口已验收。
- **P1**：按工艺与客户范围启用；被客户明确要求时可以升级为P0。
- **P0（适用工艺）**：所选产线存在该工艺时必须实现其必需记录和放行规则；不要求所有客户都启用全部工艺。
- **P2**：增强能力，待价值、数据和资源条件明确后实施。
- **继承**：已有实现可复用，仍需验证；**扩展**：保留基础模型/交互，新增MES规则；**新增**：当前抽查范围未找到完整实现。
- **内核**：所有项目共用的业务约束；**配置**：按版本管理的数据和规则；**适配**：设备/ERP等外部差异。不能将“标准化”理解为所有工厂使用同一条路线和同一阈值。

## 4. 统计与验收口径建议

1. **成品产出**按指定终点首次有效完成的成品SN统计，并明确统计对象是模组还是PACK；包装、接口重传、同工序复测不增加成品数量。
2. **首次通过率**必须明确工序、时间窗口和有效首测集合。返修后合格可影响最终良率，但不能回写成初测合格。
3. **NG、返修、报废**分别表示检测结果、处置过程和最终去向。不能把三个数简单相加当损失，也不能把不良原因条数当不良件数。
4. **线边库存**以受控库存事务台账为依据；投料动作、库存扣减和ERP回传建立关联，分别有自己的处理状态。
5. **追溯完整率**若需要作为指标，应先定义“某型号某版本所需证据集合”；不能只以有一个DHR文件判为完整。
6. **OEE**只有在排班、停机、理想节拍、生产计数和质量计数口径明确后才有可信结果；“已接设备报警”不足以完成计算。

以上均为拟定验收规则。本次没有运行代码、连接设备或取得客户工艺确认，矩阵中各项不能据此标为“已完成”。详细数据/接口及AC01–21见[开发契约](../development/contracts-and-acceptance.md)。
