# 模组 / PACK 行业功能详细设计 v0.2

日期：2026-10-22。设计方向已确认：标准功能页面、领域配置、服务端业务执行；无通用表单、无电子签名认证。具体工艺阈值、产品结构和设备报文待新项目确认。

## 1. 证据、适用范围与产品边界

- S1、S2为[调研报告](../research/materials-and-reuse-assessment.md)中的技术协议及11页工艺PDF；二者的工艺差异保留为不同模板。飞书正文仍缺失。
- **已确认产品方向**不等于**客户工艺已确认**。下列对象字段、页面与状态是设计方案；引用材料只是说明业务依据，不表示每个字段都来自原文。
- NI官方资料区分电芯、模组和PACK测试，介绍BMS通讯与充放电测试；这里只用于核对测试分类，不将研发耐久、滥用或环境验证一概列为每件产线必测。[NI应用说明](https://www.ni.com/content/dam/web/pdfs/NI_Fundamentals_Battery_Module_Pack_Test_Application_Note.pdf)
- Atlas Copco说明电池装配中的粘接、密封及导热材料应用，且工艺随电芯形态与电池设计变化。下文据此补充材料窗口与过程记录设计，不引用厂商效果数字。[电池装配点胶](https://www.atlascopco.com/en-uk/itba/industry-solutions/automotive-entry/e-mobility-and-ev-battery-assembly-process/dispensing-ev-battery-assembly)
- Vector公开资料证明烧录工具可以通过API被外部程序调用；因此MES可记录/协调烧录任务，不需自己实现全部ECU刷写协议。是否使用该厂商产品未决定。[vFlash](https://www.vector.com/en/product/vflash/)

优先级：**核心**必须具备；**工艺必选**表示该产线存在此工艺时必须具备，不能因为不是所有客户都需要就省略；**增强**需有明确需求再实现。电动汽车、储能、风冷/液冷、外购模组等不同方案不可强制套用同一套测试。

MES负责业务放行、记录与追溯；高压互锁、急停、带电操作保护及测试仪安全控制由设备系统负责。MES许可不等同于设备安全许可。首版不扩展为电池研发测试平台、上游电芯制造MES或完整售后维修系统。

## 2. 产品配置结构

制造版本应包含以下受控配置；配置页面使用明确业务字段，保存前后端均校验，不提供任意字段脚本或任意动态数据库实体。

| 配置页签 | 关键内容 | 发布校验 |
|---|---|---|
| 产品与变型 | MODULE/PACK、型号、A/B等变型、SN规则、计量单位、制造/外购来源 | 来源及身份策略明确；不得把产品代码当单件SN |
| 制造BOM | 子件物料/版本、数量/单位、SN或批次管理、替代料、投料工序 | 单位一致；替代料有明确适用范围；关键件不能缺追溯方式 |
| 装配位置 | 位置编号、父级、物料类型、方向/极性、数量约束、安装顺序、示意图坐标 | 位置不重号；所有必需位置有规则；图上位置与数据编号一一对应 |
| 电气拓扑 | 电芯/模组电气分组、串联组/并联成员、极性、传感通道和物理位置映射 | 物理装配与电气连接分开；不得只靠总数量判断串并联正确；映射完整且不重复 |
| 路线与资源 | 工序节点、前置关系、必需/适用节点、线外工序、设备组、治具/通道 | 所有可执行节点有资源/动作；图上允许的路径必须有后端实现 |
| 标准动作 | 动作类型、顺序/前置、执行角色、输入方式、证据需求、完成条件 | 不支持的动作拒绝发布；必需设备结果不能配置为只点确认即可通过 |
| 检测与配方 | 参数代码、单位、位置/通道、上下限及包含边界、必需项、采样/判定策略、设备程序版本 | 规范完整；只允许声明的单位转换；项目未确认的限值不能使用截图示例填充 |
| 返修与复测 | 可返工节点、允许拆换项、受影响测试、最大尝试/授权策略 | 拆换对象及测试失效规则有定义；不能无限复测取任一次OK |
| SOP与报告 | SOP文件版本/页码、标签模板、履历报告模板、出厂证据清单 | 文件有效；标签数据来自真实对象；报告模板不参与现场填报 |

首版变型用显式制造版本表达；允许复制配置后修改并发布。不同设备通讯字段走适配映射，不放入客户专属页面分支。尚无真实需求时不增加任意继承树、通用DSL或插件市场。

## 3. 标准动作目录

工序可包含多个动作；动作负责交互及业务语义。一个动作可复用同一页面组件，但每次执行必须有独立记录。

| 动作类型 | 页面主体 | 完成证据 | 可配置项 |
|---|---|---|---|
| IDENTIFY | 扫码、当前对象与上下文 | 已解析身份与工位访问 | 条码类型/来源、对象类型、适用工单 |
| MATERIAL_LOAD | 上料/换料清单 | 可用物料批次与上料记录 | 物料槽位、替代料、效期及清料条件 |
| ASSEMBLE | 父子装配位置图 | 有效装配关系与齐套检查 | 型号、位置、方向、数量、跨批策略 |
| DISPENSE | 胶料与区域、设备过程结果 | 区域记录、材料批次、程序、必需检测 | 区域/路径、材料窗口、计量/视觉证据 |
| PRESS_HOLD | 压装/保压状态 | 设备周期、压力/位移等结果及时间 | 测项、时间窗、所用治具/配方 |
| WELD | 焊点矩阵与缺点提示 | 每个必需点位的有效结果 | 点位、程序、检测方式和返修策略 |
| TIGHTEN | 螺栓位置图、工具结果 | 每个必需点位的有效锁附结果 | 点位顺序、程序、扭矩/角度规则 |
| MEASURE | 检测项及通道矩阵 | 完整测试运行与原始判定 | OCV/IR/DCR/EOL等规范、单位及通道 |
| LEAK_TEST | 回路/腔体、测试阶段结果 | 指定对象/回路的完整测试 | 测试类型、介质/程序标识、要求参数 |
| FLASH_VERIFY | 软件包与BMS实读信息 | 烧录/核验结果、实际版本 | 型号兼容清单、软件/标定版本、验证项 |
| CYCLE_TEST | 设备通道、长时任务进度 | 有效充放电任务与摘要/曲线 | 容量/能量/终态等所需结果、方案版本 |
| TIMED_HOLD | 静置/烘烤等起止与倒计时 | 真实时间、设备运行与成员清单 | 最短/最长时间、开始依据、重启策略 |
| MANUAL_INSPECT | 固定类型的检查项、缺陷/照片 | 逐项结果、操作者与必要附件 | 检查项规范、必填证据、缺陷原因 |
| MANUAL_CONFIRM | 操作说明、确认按钮 | 人员、时间、说明版本及配置要求的证据 | 角色、前置条件；不采用签名认证 |
| LABEL_PACK | 标签预览、打印与包装扫描 | 打印任务、复核和包装关系 | 模板、打印机、标签码/箱码规则 |

装配解绑、报废、偏差放行不是可随意拖入正常工序的普通动作；它们属于质量/返修服务，要求业务原因和权限。动作组件不可直接修改数据库状态，统一提交后端业务命令。

## 4. 行业能力逐项设计

### PK01 电芯来料与配组资格（核心；配组优化为增强）

- **依据**：S1电芯上线校验；S2第3页OCV/IR。自动配组算法并未由材料确认。
- **字段**：供应商、批次、物料/型号、原始条码/内部身份、来料质量状态、OCV/IR/容量分档（有来源才录入）、测试时间/设备/单位、测试条件、数据来源批次。
- **页面**：接收/导入、条码映射、检验结果和不可用原因。外购模组可直接进入模组层，不强制伪造其内部电芯。
- **规则**：重复码/来源冲突转人工核对；型号、质量、测试有效期、混批和配组差异按产品规范检查；有OCV/IR值不等于自动满足配组条件。普通ACIR与DCR不可仅因单位相同互相替用。
- **验收**：过期测试、缺少必需测试、错误单位和已占用电芯分别拦截；补导重复文件不增加物料；可追到上游原始结果。

### PK02 电芯—模组—PACK装配谱系（核心）

- **依据**：S1绑定与换芯；S2第3–8页装配。
- **字段**：父/子追溯对象、装配位置、来源/目标工单、制造版本、绑定/解除时间、操作员/设备、原因、返修单、当前质量与实物去向。
- **规则**：有效父件占用唯一、位置不冲突、禁止自绑/成环；数量与BOM一致；来源工单和目标PACK工单可以不同，需投料授权。供料托盘和周转箱是载具关系，不是永久产品组成。
- **页面**：物理位置示意+待装/已装/异常计数；子件扫描后由版本规则定位，必要时操作员确认位置。
- **验收**：并发绑定同一子件仅一次成功；拆换后当前/历史/出厂视图不同且都能解释；拆出件不自动变成合格库存。

### PK03 物理位置、电气拓扑与BMS通道（核心建模；具体映射按工艺必选）

- **依据**：S2 A/B模组、FPC与PACK连接；通道映射是为可靠追溯补充的设计。
- **字段**：物理slot、串联组、并联成员、极性/方向、采样板/通道、温度探头位置、适用拓扑版本。
- **规则**：不能用“第8次扫入”永久充当“第8号电气通道”；设备通道有显式映射；同一测试规范说明预期通道数量及是否允许不适用项。
- **验收**：A/B错型、极性/位置不符合、缺通道/重通道/未配置映射不能通过；点击某电压异常能定位物理位置及子件SN。

### PK04 胶料、导热材料与工艺时间窗（工艺必选）

- **依据**：S2点胶、保压、静置与密封；S1工艺数据。材料开封/混合时限是产品设计补充，数值待工艺确认。
- **字段**：胶料批次/容器、有效期、开封/混合/上料时间、材料体系、工位槽位、区域/轨迹、程序/配方、实际用量、必需的压力/温度/混合比、视觉结果与图片。
- **规则**：仅要求设备及工艺实际提供的参数；双组分与单组分配置不同。开封可用时长、点胶至合装/固化窗口分别建模；清料/换胶留记录；时间超窗触发处置，不能只手工改开始时间。
- **验收**：胶过期、开封超时、缺区域结果、缺必要图片或点胶后超时均有明确处理；返修新增耗胶独立记账。

### PK05 堆叠、压装、保压与静置（工艺必选）

- **依据**：S1组件堆叠；S2堆叠保压、烘烤静置。
- **字段**：设备周期、治具、对象/装配版本、压力/位移/高度等确认测项、开始/结束、程序版本、曲线引用。
- **规则**：计时起点由明确现场事件决定；页面打开时间不是工艺开始时间；共用烘箱记录一次运行及其成员，成员进出变化须留痕。
- **验收**：未达到必需保压/静置条件不能转序；断电中断、成员换入、设备时钟异常不会被自动计为完成。

### PK06 焊接与焊点质量（工艺必选）

- **依据**：S1侧缝/顶盖焊；S2汇流排焊与视觉检测。
- **字段**：焊接对象/部位、焊点/焊缝编号、设备/头号、配方版本、实际设备提供的能量/功率/时间等、设备结果、检测结果、图像/曲线、尝试编号。
- **规则**：区分焊接过程完成与焊后检验合格；必需焊点均有证据；重焊开启新尝试，不能覆盖原失败；更换电芯/汇流排后相关焊点证据失效待复核。
- **验收**：缺一点、设备错程序、检测NG、重复点位或跨SN上传不通过；返修后仍可查看原点位全部尝试。

### PK07 锁附与扭矩/角度（工艺必选）

- **依据**：S2模组/电连接/上盖紧固；具体参数和工具协议待确认。
- **字段**：螺栓位置、顺序、工具/控制器、轴号、程序号/版本、扭矩/角度及单位、结果、曲线、运行/尝试ID、拆卸或复紧记录。
- **规则**：设备结果绑定访问和点位；复用一个OK结果凑齐多个螺栓无效；反松/拆卸不能当合格锁附；不把“重新点确认”当重新锁紧。
- **验收**：程序不匹配、少螺栓、乱点位、重复报文被识别；换上盖/拆开连接后，按复测规范重开相关点位。

### PK08 冷却回路与箱体气密（工艺必选）

- **依据**：S1两次液冷气密与箱体气密；S2液冷管路、合盖后气密。
- **字段**：对象、回路/腔体、阶段（预装/装配后/返修后等）、测试介质、程序/方法、充压/稳定/检测时间、压力/压降或漏率及单位、温度（工艺要求时）、结果/曲线。
- **规则**：压降与漏率是不同测项，不直接互换；不同回路、阶段和测试方法的OK不可替代；维修冷却管或重新开盖后的复测按影响规则触发。
- **验收**：只做液冷测试不能满足箱体测试；测试阶段不匹配拒绝占用本次必测项；断测/缺数据不算OK。

### PK09 绝缘、耐压、DCR与电性能（工艺必选）

- **依据**：S2模组电性能、绝缘耐压、DCR及PACK绝缘/EOL；S1两次EOL。
- **字段**：测试运行、项目、测点/通道、极性/回路、测试条件/程序、实际值/单位、规范上下限、设备判定、MES判定、综合状态、原始文件。
- **规则**：绝缘电阻、耐压泄漏电流、DCR分别定义；设备异常、数据缺失、业务NG分开；没有必要数据时不能只用设备总OK替代要求明细。
- **验收**：错单位、漏测、数组通道不足、设备NG但MES值在范围内等场景有明确判定；MES不直接实现高压安全联锁。

### PK10 BMS/关键电子件与软件一致性（关键件追溯核心；烧录为工艺必选）

- **依据**：S2 BMS、Hall、线束等；烧录/软件追溯是行业设计补充，不宣称历史材料已要求现场烧录。
- **字段**：BMS/采样板/关键件SN或批次、硬件版本、实读软件/标定版本、目标软件包ID与哈希、兼容清单、工具版本、烧录任务、结果、失败原因、读回核验、通讯配置版本。
- **规则**：预编程外购BMS可只核验，无需强制现场烧录；下发成功不等于烧录成功；烧录成功后仍需实读/功能验证；软件包哈希用于识别文件内容，不是人员电子签名。授权软件包由受控文件与角色权限管理。
- **验收**：错硬件/软件组合、读回不一致、烧录中断不能放行；换BMS或软件变更触发已配置的相关复测；工具协议及密钥由设备/工具负责，不放进浏览器配置。

### PK11 EOL静态/动态与通讯诊断（工艺必选）

- **依据**：S2第8页多次EOL；NI资料辅助核对BMS通讯类别。
- **字段**：测试阶段、方案版本、PACK身份、设备/通道、BMS版本、测项/子项、故障码与状态、时刻、总结果及原始报告；工艺需要时含互锁、接触器/预充等测试结果。
- **规则**：具体子项由设备及产品规范给出；MES接收测试结果，不自行控制高压动作；区分初测、复测及不同阶段；CAN/诊断解析在设备适配端处理，不要求MES管理端直接接总线。
- **验收**：前阶段EOL不能顶替后阶段；需要关注的故障码未处理时不能放行；清除故障码操作留痕，不抹去原始诊断结果。

### PK12 充放电、容量/能量与出厂状态（工艺必选）

- **依据**：S1并行充放电设备；S2容量测试。终态SOC等放行要求为待确认设计项。
- **字段**：设备任务/通道、SN绑定、开始/结束、方案/工步、容量Ah、能量Wh/kWh、SOC/电压/温度等实际所需值、曲线文件、停机/中断原因。
- **规则**：任务结束不等于质量合格；Ah与Wh不可混用；不同通道结果不串件；长时任务重启可恢复追踪；出厂状态按工艺规范配置，不在本版设固定SOC数值或运输法规阈值。
- **验收**：中断任务、错通道、摘要与曲线归属不一致分别处理；外部任务查询/补传不会重复产出或扣料。

### PK13 载具、治具与多通道资源（工艺必选）

- **依据**：S1平行设备；S2线外工序；载具追踪为现场执行补充设计。
- **字段**：载具/治具ID、设备通道、位置、装载SN、占用起止、资格/有效期（需确认）、设备运行ID。
- **规则**：设备用载具码上报时，按发生时点的有效装载关系解析；清空载具不删除历史；重夹/换位更新关系；资源占用由后端控制，不依赖浏览器会话。
- **验收**：两个任务不能同时占用同一通道；晚到报文不能绑定给后来换入的SN；离线装载变化有明确对账策略。

### PK14 不良隔离、拆换与测试有效性（核心）

- **依据**：S1不良处置与换芯；产品设计补足父件影响与测试失效。
- **字段**：缺陷对象/位置、原始失败、发现工序、影响父件、处置类型、返修工单、拆入/拆出件、材料耗损、批准记录、应复测项和关闭依据。
- **规则**：历史结果保留，但可因后续结构变化变为“不再满足当前放行条件”；使用“测试依赖哪些部件/配置”的影响矩阵。默认不猜测所有测试永久有效，未定义的变更转质量评估。
- **验收**：换芯后相关焊接/电性能待复核；换BMS后软件/通讯相关测试待复核；拆盖后相关密封/锁附测试待复核；具体复测集合由发布规则决定，不能把示例当所有产品强制规范。

### PK15 标签、包装、质量放行与交付快照（核心）

- **依据**：S1模组编码/标签；S2标签称重包装入库。
- **字段**：内部SN、客户码、标签版本、打印/重印任务、打印机、复核结果、包装箱/托盘、重量、交接单、放行记录、交付快照ID。
- **规则**：打印成功不是生产完工或质量放行；重复打印不新建产品身份；标签码与实物SN核对；同一成品不能同时在两个有效包装关系内；外部入库回执与实物状态分开。
- **验收**：有未闭环质量锁定、必测缺项或物料关系不全时不能正常放行；重印有原因；交付后变更不覆盖原交付快照。

### PK16 批次/设备/程序变更的影响追查（核心）

- **依据**：S1正反追溯；历史影响计算为设计补充。
- **输入**：电芯/胶料/组件批次、设备、工具、配方/软件版本、工序、时间范围或不良点位。
- **输出**：曾使用与当前使用对象、受影响模组/PACK、在制/在库/已交付状态、证据与缺失范围；候选影响清单由质量角色确认后锁定。
- **规则**：曾装入后拆出的电芯仍出现在历史影响查询中；批次混料/重工实际用料均覆盖；查询发现影响不自动改写全部成品为报废。
- **验收**：按旧电芯或旧胶批能查到历史成品；导出含查询条件、时点、范围和缺失证据提示。

### PK17 首件、换型与生产准备（核心）

- **依据**：S1首件放行、工单切换、清退料。
- **字段**：产线/工位会话、工单、制造版本、设备程序实读、上料状态、SOP版本、首件样本/结果、准备检查和批准人。
- **规则**：换型号、换配方、换关键料或维护后是否重做首件由工艺规则规定；人工确认程序号与设备实读要区分来源；未完成准备检查不得正常开工。
- **验收**：旧工单余料/在制未处置不能静默切换；批准旧型号首件不能放行新型号；错误程序确认不能被界面显示掩盖。

### PK18 指标与生产运营（核心基础指标；OEE/SPC增强）

- **基础**：按模组/PACK分别统计计划、有效产出、在制、待处置、报废、返修与首次通过；工序/动作/测试运行粒度区分。
- **规则**：复测不增加产量；最终合格不回写首次结果；父件报废和拆出子件耗损避免重复计同一指标；时间按工厂时区/班次归属，设备发生时间与接收时间均保留。
- **增强**：OEE需排班、理想节拍、停机分类及计数口径；SPC需采样、分组和测量条件。准备好数据后实现，不以漂亮图表替代可靠来源。
- **验收**：每个指标下钻到原事件；对账能说明迟到数据、返修及冲销对统计的影响。

## 5. 页面实施规格

| 页面 | 布局与查询 | 动作 | 权限/异常反馈 |
|---|---|---|---|
| 制造版本工作区 | 左侧版本；中间配置页签；右侧发布检查/差异 | 新建、复制、编辑草稿、校验、发布、停用 | 工艺角色；被引用版本保护；缺项定位到具体点位/动作 |
| 工位执行台 | 固定上下文、扫码区、动作步骤、中央功能区、SOP/历史侧栏 | 识别、开始、执行、结束；根据动作类型显示按钮 | 设备/人员权限分别核验；只读结果与可输入项视觉区分 |
| 装配工作台 | 产品位置图+子件列表+电气映射查看 | 扫描绑定、齐套校验；拆换跳转返修 | 显示已占用父件和冲突位置；不能在正常页面直接删绑定 |
| 测试/锁附/焊接工作区 | 点位矩阵、设备状态、实际/规范值、尝试历史 | 自动采集、受控重试、查看曲线 | 人工补录有明确来源；设备NG不改成手填OK |
| 质量处置与返修 | 失败证据、当前结构、影响测试、处置时间线 | 隔离、评估、返修、拆换、复测、报废、批准/关闭 | 按角色授权并保存意见；无签名认证；未定义影响范围不能自动恢复 |
| 单件履历 | 当前/历史/交付三视图、装配树、工序时间线 | 查询子件、原始报告、影响清单、导出 | 显示追溯边界与缺项；只读证据，改动走原业务入口 |
| 设备与接口监控 | 在线、队列、任务、冲突、未关联记录 | 查询、重试、人工关联核对 | 重试不重复业务效果；不能靠后台直接改OK字段 |
| 包装/交付 | SN/箱码、称重、标签与质量条件 | 打印、复核、装箱、拆箱、交接 | 重印留原因；质量未放行不得正常交付 |

## 6. 首期范围与待确认配置

开发先实现PK01/02/03基础、PK14–18和通用测试/设备收件框架；从PK04–13中按首条线真实工艺选取。未选工艺可以没有页面入口；被选工艺的必需数据和放行约束不能推迟到上线后。

| 待确认 | 影响 | 未确认时的处理 |
|---|---|---|
| 首期模组/PACK/外购模组、产品型号与拓扑 | 装配层级、页面和追溯深度 | 仅用明确标识的演示配置，不发布生产版本 |
| 位置图、串并联及BMS通道映射 | 点位与测量归属 | 不根据扫描顺序猜测映射 |
| 检测规范、单位/限值/边界、数据有效期 | 自动判定与放行 | 无规范不进行真实自动放行 |
| 设备协议、报文样本、程序版本和握手时序 | 设备适配与重传 | 先模拟验收，标明真实设备接口未验收 |
| 胶料/保压/静置窗口、首件重置规则 | 时间条件与准备检查 | 只实现机制，参数待工艺确认 |
| 拆换部件与复测矩阵 | 历史测试有效性 | 进入质量评估，不默认全部继续有效 |
| BMS预编程或现场烧录、目标版本来源 | 是否启用FLASH_VERIFY | 不默认建设烧录平台 |
| 生产节拍、曲线/图片规模、离线授权与恢复指标 | 性能、存储和部署 | 留明确待决值，不给无依据容量承诺 |

上述缺口不阻止基础工程、身份模型、配置结构和模拟闭环开发，但会阻止对应真实工艺配置和现场验收。技术契约详见[开发契约](../development/contracts-and-acceptance.md)。
