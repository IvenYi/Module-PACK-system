## 发现并修复

| 问题 | 修复与验证 |
| --- | --- |
| 产品同编码多版本无法在主表区分 | 增加物料版本列，保留已有列偏好；浏览器查询确认 1.0 / 1.1 分行可辨，详情版本一致 |
| 物料保存后产品/目录/相关候选短时间仍旧 | 失效对应实时目录缓存；新增、子版本、编辑、导入、删除、失败及非物料操作边界的实际 QueryClient 回归通过 |
| 制造版本变更后产品展开及工单候选未立即更新 | 保存、发布、删除后刷新对应工厂的展开和候选缓存，保留历史工单与放行缓存 |
| 新工单不立即进入对象建档候选、建档后工单计数滞后 | 工单保存/接单刷新建档候选；对象建档刷新工单计数、详情和候选；真实回调回归验证已建对象后不显示编辑 |
| 工单制造版搜索残留、筛选变化导致当前选择空白、清除不完整 | 新增/编辑重置搜索，独立保留当前完整选择，Clear 同时清空；浏览器复查新制造版候选、冻结摘要及清除操作 |
| 工单保存提示盖住详情关闭按钮 | 提示移到左下并避开底部操作区；浏览器命中检查及保存后关闭、接单成功 |
| BOM 行浮动用料标签压住分隔线 | 取消重复浮动标签，使用表头及行级可访问名称；浏览器复制窗口复查三行控件布局，取消且不另存重复版本 |
| 制造详情与选择项缺少产品版本 | 展示冻结产品版本，优先使用冻结依据；浏览器确认 1.1 |
| 工作台工位不能按编码查询 | 选项包含名称、编码、执行模式；实际按 ST-HOME-010 / ST-HOME-020 查询并选择成功 |
| 工作台检验表在 1280×720 被压缩到只剩边框，结论无法点击 | 装配及检验输入表用自然高度容器；检验表父容器由 2 px 恢复至 90 px，通过工作区滚动实际选择并提交人工终检 |
| 已质量合格仍提示“尚不满足放行” | 单独显示质量合格、无需重复申请的成功说明；浏览器核对 |
| 历史放行快照的核查前状态容易被当作当前状态 | 增加核查时状态上下文、标题和提示，保留原数据和摘要；浏览器打开快照复查 |
| 窄窗口页签及制造工序左右分栏过宽 | 质量/制造页签可滚动；制造工序在窄窗口改上下排列。此项为代码布局修正，本轮未实测 320/360 px 设备视口 |
